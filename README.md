
## Project Overview

This project performs Exploratory Data Analysis (EDA) on a Delhi Uber ride dataset containing 100,000 ride records. The objective is to understand booking trends, ride cancellations, payment methods, ratings, ride distance, booking value, and identify inconsistencies in the dataset.

## Objectives

* Understand the structure of the dataset.
* Clean missing and inconsistent values.
* Analyze ride booking patterns.
* Visualize important trends using charts.
* Derive business insights from the data.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

> This repository is being updated through multiple meaningful commits to reflect the complete EDA workflow.
